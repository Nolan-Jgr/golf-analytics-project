# Golf Analytics: Player Performance & Tournament Analysis
### Overview
This project is an end-to-end golf analytics project designed to analyze player performance, tournament results, scoring, and earnings using a fictional golf dataset.

The goal of the project is to demonstrate the complete data analytics workflow, from raw data preparation and exploratory analysis to SQL analysis, dashboard development, predictive modeling, and business recommendations.

The project is being developed as a portfolio project to demonstrate practical data analytics skills.
### Objectives
>Analyze golf player performance
>Identify factors associated with lower scores
>Compare player consistency and performance
>Analyze tournament difficulty
>Examine relationships between golf statistics and earnings
>Develop interactive dashboards
>Build predictive models for player performance
>Translate analytical findings into actionable insights
### Dataset
The project uses a fictional golf performance dataset containing 25,000 records.

The dataset includes information related to:

>Player information
>Age
>Tournaments
>Golf courses
>Course par
>Driving distance
>Fairways hit
>Greens in regulation
>Putts
>Birdies
>Bogeys
>Scores
>Strokes gained
>Earnings

The dataset is fictional and was created specifically for analytics practice and portfolio development.
